# Checklist trước khi nộp

- [ ] Nguồn Python có đủ module, requirements đã chốt, README chạy được theo bản thật.
- [ ] Report.pdf đủ mục; có phân công/% đóng góp thực tế, công thức và bảng/chart thật.
- [ ] References và appendix AI/prompts đúng việc đã dùng.
- [ ] Link video Drive trong Report.pdf; 5–10 phút, narration/subtitles Việt/Anh.
- [ ] Link Drive ai có link xem được; kiểm tra bằng cửa sổ incognito.
- [ ] ZIP/RAR mang tên `MSSV1_MSSV2_...` theo đề.
- [ ] Nếu gói lớn hơn 20MB: dùng link Drive đúng quyền theo đề.
- [ ] Không đóng gói `.git`, `.venv`, `.env`, cache, file tạm hoặc secret.
- [ ] Có bảng/test/evidence đã chọn trong report; không vô tình bỏ vì ignore outputs.
- [ ] Thử giải nén ở thư mục mới; người code xác nhận hướng dẫn chạy đúng.
- [ ] Chốt trước deadline; không sửa sau hạn.

Ví dụ tổ chức **gói nộp cuối**, khác với scaffold hiện tại:

```text
MSSV1_MSSV2_.../
  Source/
    main.py
    README.md
    requirements.txt
    ... các package, puzzle, assets cần chạy ...
  Report.pdf
```
